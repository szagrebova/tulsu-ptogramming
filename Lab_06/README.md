# Лабораторная работа №6: Шаблоны классов (одномерный массив)

**Студент:** Загребова С.В.  
**Дисциплина:** Программирование на языке C++

## 🎯 Цель работы
Получить практические навыки разработки объектно-ориентированных программ на языке C++ с использованием шаблонов классов. Изучить принципы обобщенного программирования.

## 📋 Задание (Вариант 2)
Создать шаблон класса для работы с одномерным массивом. Выполнить тестирование путем создания и обработки массивов, содержащих элементы различных типов (например, сортировка элементов массивов различными методами).

## 📂 Структура проекта
* `Array.h` — реализация шаблонного класса `Array<T>`:
  * Хранение элементов любого типа (`int`, `double`, `std::string` и др.).
  * Реализовано **«Правило трех»**: деструктор, конструктор копирования и перегруженный оператор присваивания (для предотвращения утечек памяти при работе с динамическими массивами).
  * Перегрузка `operator[]` для безопасного доступа к элементам (с проверкой выхода за границы).
  * Алгоритмы сортировки: **метод пузырька** (`sortBubble`) и **метод выбора** (`sortSelection`).
* `InputUtils.h` / `InputUtils.cpp` — модуль безопасного ввода целых чисел.
* `main.cpp` — точка входа, содержащая шаблонную функцию `testArray<T>()`, которая позволяет тестировать класс на разных типах данных.

## ⚙️ Особенности реализации
* **Обобщенное программирование:** Один и тот же класс `Array` используется для целых чисел, чисел с плавающей точкой и строк.
* **Современный C++ (C++17):** В методе `inputFromKeyboard()` используется конструкция `if constexpr (std::is_same_v<T, std::string>)`. Это позволяет на этапе компиляции определить, является ли тип строкой. Если да — используется `std::getline` (чтобы можно было вводить строки с пробелами, например, «мама мыла раму»). Если число — обычный `cin >>`. 
* **Безопасность:** Проверка индексов в `operator[]` с выбросом исключения `std::out_of_range` при попытке выйти за пределы массива.
