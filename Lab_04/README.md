## 🎯 Цель работы
Получить практические навыки разработки объектно-ориентированных программ на языке C++. Изучить механизм перегрузки операторов, работу с конструкторами, обработку исключительных ситуаций и передачу массивов объектов в функции.

## 📋 Задание (Вариант 2)
Определить класс «Дробь» – `Fraction` в виде (m/n). 
Класс должен содержать несколько конструкторов. Реализовать методы для сложения, вычитания, умножения и деления дробей. Перегрузить операции сложения, вычитания, умножения, деления, присваивания и операции отношения. 
Создать массив объектов и передать его в функцию, которая изменяет каждый элемент массива с четным индексом путем добавления следующего за ним элемента массива.

## 📂 Структура проекта
* `Fraction.h` / `Fraction.cpp` — реализация класса дроби:
  * **Конструкторы:** по умолчанию, с одним параметром (целое число), с двумя параметрами, конструктор копирования.
  * **Инкапсуляция:** приватные поля `m` (числитель) и `n` (знаменатель), защищенные от некорректных значений.
  * **Сокращение дробей:** приватный метод `reduce()` с использованием алгоритма Евклида (НОД).
  * **Перегрузка операторов:** арифметические (`+`, `-`, `*`, `/`), присваивание (`=`), сравнение (`==`, `!=`, `<`, `>`, `<=`, `>=`).
* `InputUtils.h` / `InputUtils.cpp` — модуль безопасного ввода, включая функцию `readNonZeroInt()` для защиты знаменателя от нуля.
* `main.cpp` — интерактивное меню, демонстрация работы перегруженных операторов и функция `processEvenIndices()` для обработки массива.

## ⚙️ Особенности реализации
* **Безопасность:** Обработка исключений (`throw invalid_argument`) при попытке создать дробь с нулевым знаменателем или делении на ноль.
* **Чистота кода:** Перегрузка операторов использует уже написанные методы класса (`add`, `sub`, `mul`, `div`), что исключает дублирование кода.
* **Работа с памятью:** Массив дробей создается динамически (`new Fraction[n]`), а память корректно освобождается в конце.
* **Логика обработки массива:** Функция `processEvenIndices` изменяет элементы с четными индексами (0, 2, 4...), прибавляя к ним следующий элемент. Последний элемент остается без изменений, если его индекс четный.
