**Студент:** Загребова С.В.  
**Дисциплина:** Программирование на языке C++

## 🎯 Цель работы
Получить практические навыки разработки программ на языке C++ с использованием нелинейных структур данных: деревьев. Изучить принципы балансировки и рекурсивной обработки структур данных.

## 📋 Задание (Вариант 2)
Используя генератор случайных чисел для задания ключей и значений полей данных, разработать программу для построения сбалансированного дерева, содержащего не менее 20 узлов.
**Индивидуальное задание:** Найти количество узлов на четвертом уровне данного дерева (корень считать первым уровнем).

## 📂 Структура проекта
Код разделен на модули для чистоты архитектуры:
* `AVLTree.h` — объявление структуры узла `Node` и интерфейса класса `AVLTree` (публичные и приватные методы).
* `AVLTree.cpp` — реализация логики AVL-дерева:
  * Вычисление высоты и баланса узлов;
  * Малые левый и правый повороты для балансировки;
  * Рекурсивная вставка элемента с последующей балансировкой;
  * Симметричный обход (in-order) для вывода элементов по возрастанию;
  * Метод `printTree` для визуализации структуры дерева (повернутой на 90°);
  * Рекурсивный подсчет узлов на заданном уровне.
* `main.cpp` — точка входа. Генерирует 25 случайных уникальных ключей, вставляет их в дерево и выводит результаты.

## ⚙️ Особенности реализации
* **AVL-балансировка:** Дерево автоматически поддерживает свою высоту сбалансированной (разница высот поддеревьев не превышает 1). Это гарантирует скорость операций вставки и поиска на уровне O(log n).
* **Защита от дубликатов:** При генерации ключей используется `std::set`, чтобы исключить повторения.
