# Лабораторная работа №3: Простейшие классы и объекты

**Студент:** Загребова С.В.  
**Дисциплина:** Программирование на языке C++

## 🎯 Цель работы
Получить практические навыки разработки объектно-ориентированных программ на языке C++: проектирование простейших классов, использование инкапсуляции, конструкторов и методов.

## 📋 Задание (Вариант 2)
Создать класс `Abiturient` (Абитуриент), содержащий поля: Фамилия, Имя, Отчество, Адрес, Оценки (за 4 предмета).
Создать массив объектов. Реализовать программу, которая выводит:
**а)** Список абитуриентов, имеющих неудовлетворительные оценки;
**б)** Список абитуриентов, сумма баллов у которых не меньше заданной;
**в)** N абитуриентов, имеющих самую высокую сумму баллов, а также список абитуриентов с полупроходным баллом.

## 📂 Структура проекта
Код разделен на логические модули:
* `Abiturient.h` / `Abiturient.cpp` — описание и реализация класса `Abiturient`. 
  * Используются закрытые поля (`private`) и публичные методы доступа (`set`/`get`), что реализует принцип **инкапсуляции**.
  * Методы `getSum()` (подсчет суммы баллов) и `hasBadGrades()` (проверка на двойки) вынесены внутрь класса.
* `InputUtils.h` / `InputUtils.cpp` — вспомогательный модуль для безопасного ввода данных. Защищает программу от падения при вводе букв вместо цифр или некорректных значений.
* `main.cpp` — точка входа. Содержит интерактивное меню и логику обработки массива объектов (поиск, сортировка, вывод).

## ⚙️ Особенности реализации
* **Безопасный ввод:** Благодаря `InputUtils`, программа не зацикливается и не ломается при некорректном вводе (например, при вводе оценки `6` или буквы `а`).
* **Работа с памятью:** Массив абитуриентов создается динамически (`new Abiturient[n]`), а в конце программы память корректно освобождается (`delete[] arr`).
* **Сортировка:** Для поиска топ-N студентов используется сортировка массива указателей (чтобы не копировать сами объекты), реализованная методом выбора.
* **Полупроходной балл:** Алгоритм автоматически определяет балл последнего студента из топ-N и выводит всех, у кого совпадает такая же сумма (как в реальном конкурсе на поступление).
