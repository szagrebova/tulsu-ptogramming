## 🎯 Цель работы
Получить практические навыки разработки объектно-ориентированных программ на языке C++: разработка классов для работы с динамическими структурами данных и организация файлового ввода-вывода.

## 📋 Задание (Вариант 2)
Построить класс для работы со стеком. Элемент стека – целое число. 
Ввести две неубывающие последовательности чисел в два стека. Использовать третий стек для слияния двух последовательностей в одну неубывающую.

## 📂 Структура проекта
Код разделен на модули:
* `IntStack.h` / `IntStack.cpp` — реализация класса стека на базе односвязного списка:
  * Реализовано **«Правило трех»**: деструктор, конструктор копирования (глубокое копирование) и перегруженный оператор присваивания. Это защищает программу от утечек памяти и двойного удаления.
  * Методы `saveToFile()` и `loadFromFile()` для работы с текстовыми файлами.
* `InputUtils.h` / `InputUtils.cpp` — модуль безопасного ввода данных (защита от ввода букв вместо чисел).
* `main.cpp` — точка входа. Содержит интерактивное меню и функцию `mergeStacks()`, реализующую алгоритм слияния двух стеков.

## ⚙️ Особенности реализации
* **Глубокое копирование:** При передаче стека в функцию `mergeStacks` (по значению) создается его полная копия. Оригинальные стеки не портятся. Для этого написан кастомный конструктор копирования.
* **Алгоритм слияния:** Функция `mergeStacks` извлекает элементы с вершин двух стеков, сравнивает их и помещает в результирующий стек. На выходе получается стек, который при выводе (от вершины) образует неубывающую последовательность.
* **Файловый ввод-вывод:** Программа умеет читать данные из файлов `input1.txt` и `input2.txt`, а также сохранять результат в `output.txt`.
