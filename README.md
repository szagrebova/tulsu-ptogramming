## 👋 О репозитории
Этот репозиторий содержит мои лабораторные работы за 3 семестр, выполненные в рамках изучения языка **C++**. 

Здесь собраны проекты, демонстрирующие навыки работы с:
*   Динамическими структурами данных (списки, стеки, очереди);
*   Нелинейными структурами данных (AVL-деревья);
*   Объектно-ориентированным программированием (ООП: классы, наследование, полиморфизм);
*   Шаблонами классов и перегрузкой операторов;
*   Созданием графического интерфейса (Windows Forms) и работой с файлами.
